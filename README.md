# Andre Ilyas - Personal Portfolio

Portofolio personal Andre Ilyas dengan tema **Dark Space / Galaxy**, antarmuka
glassmorphism, dan interaksi berbasis JavaScript. Website ini dibuat untuk
menampilkan proyek, keahlian, pengalaman, serta jalur komunikasi profesional.

## Live Preview

Jalankan project secara lokal atau deploy folder ini ke GitHub Pages, Vercel,
atau layanan hosting statis lainnya.

## Fitur

- Floating navigation bar dengan navigasi ke setiap section.
- Hero section dengan profil, tagline, CTA, dan tautan media sosial.
- Section About untuk memperkenalkan latar belakang dan keahlian.
- Tech stack dan project showcase dengan kartu interaktif.
- Live demo [Web Kesehatan - Demam Berdarah](https://andreilyas.github.io/projectwebkesehatan/) beserta repository GitHub-nya.
- Form kontak dan area guestbook/interaksi pengunjung.
- Responsive layout untuk desktop, tablet, dan perangkat mobile.
- Visual dark space dengan efek glow, bintang, dan glassmorphism.

## Teknologi

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome untuk ikon
- Google Fonts

Project saat ini merupakan website statis tanpa proses build atau dependency
tambahan.

## Menjalankan Secara Lokal

1. Clone repository:

   ```bash
   git clone https://github.com/andreilyas/portofolio.git
   cd portofolio
   ```

2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.

## Arah Pengembangan

### Phase 1 - Setup & Design System

- Menyempurnakan struktur folder dan design system.
- Menambahkan latar belakang animasi bintang serta efek glassmorphism.

### Phase 2 - Header & Hero

- Menyempurnakan floating navbar, teks CTA, social cards, dan profile frame.
- Menambahkan widget musik atau playlist coding bila diperlukan.

### Phase 3 - About & Credentials

- Menambahkan resume, pendidikan, pengalaman, dan statistik proyek.

### Phase 4 - Tech Stack & Projects

- Menambahkan filter Projects, Certificates, Awards, dan Tech Stack.
- Melengkapi detail teknologi, live demo, dan repository setiap project.

### Phase 5 - Contact & Polishing

- Menghubungkan form kontak dan guestbook ke backend atau layanan form.
- Mengoptimalkan aksesibilitas, performa, dan responsiveness.
